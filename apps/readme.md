# Apps

Homebrew packages and Mac App Store apps backup/restore.

`Brewfile` lists taps, formulae installed on request, casks and Mac App Store
apps. It is generated by [`brew bundle dump`](https://docs.brew.sh/Brew-Bundle-and-Brewfile).

## Backup everything

From the repo root, regenerate the `Brewfile`:

```shell
make apps-backup
```

## Install everything from backup

Run from the repo root (`~/.dotfiles`):

```shell
make apps-install
```

> [!NOTE]
> Mac App Store apps need you to be signed in to the App Store first.

To see what changed since the last backup, regenerate it and diff:

```shell
make apps-backup && git diff apps/Brewfile
```

## Install MongoDB tools and shell only

The tools below come from the `mongodb/brew` tap and are not in the
`Brewfile`:

```shell
brew tap mongodb/brew
brew trust --formula mongodb/brew/mongodb-community-shell mongodb/brew/mongodb-database-tools
brew install mongodb/brew/mongodb-community-shell
brew install mongodb/brew/mongodb-database-tools
```

More info: https://www.mongodb.com/docs/manual/tutorial/install-mongodb-on-os-x/
